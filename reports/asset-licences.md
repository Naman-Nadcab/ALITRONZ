# Visual asset provenance

No third-party models, HDRIs, textures, photographs, screenshots, logos, or generated-image assets were added in this transformation.

The visual system is original to this repository and is produced from:

- Procedural Three.js geometry and materials in `components/three/core-canvas.tsx`.
- An original SVG fallback in `components/three/core-fallback.tsx`.
- Original service-family SVG scenes in `components/visuals/family-visual.tsx`.
- Original concept-project SVG plates in `components/project-plate.tsx`.
- Original CSS lighting, spatial planes, interface surfaces, and responsive compositions in `app/globals.css`.

There are therefore no external visual-asset source URLs, creator credits, or third-party asset licence terms to record.
